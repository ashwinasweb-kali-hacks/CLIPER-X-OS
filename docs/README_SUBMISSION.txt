--------------------------------------------------------------------------------
1. cliper_x_bom_hardware.csv
   - Complete Bill of Materials with unit pricing, vendors, and total ~$375 BOM.

2. cliper_x_pc_design_specs.csv
   - Hardware bus interfaces (PCIe, MIPI DSI, I2C, USB 3.0, PWM).
   - Operating voltage, pinout assignments, and current draw budgets.

3. github_repository_links.txt
   - GitHub repositories for CLIPER-X-OS, JARVIS, and developer profile.
   - YouTube video demo & devlog placeholders.
   - Hack Club Stardance grant tier metadata.

4. STARDANCE_SUBMISSION.md
   - Comprehensive X-Tier proposal including ASCII system architecture,
     wiring schematics, power budget breakdown, and software stack overview.

5. HARDWARE_BUILD.md
   - Step-by-step physical assembly guide for the 3D-printed chassis,
     HAT stack, cabling routing, and active thermal management.
